# Centro de Soporte — PranaKaia

Gracias por usar y contribuir a **PranaKaia**. Para garantizar una operación fluida y una resolución eficiente de problemas, hemos establecido los siguientes canales de soporte oficiales.

## 🛠 Soporte Técnico (Desarrollo)

Si eres un desarrollador trabajando en el monorepo y encuentras problemas técnicos:

1.  **Documentación Primero**: Revisa la carpeta [`/docs`](./docs) y el [`README.md`](./README.md). La mayoría de los procesos operativos (despliegue, entorno, arquitectura) están documentados allí.
2.  **GitHub Issues**: Si has encontrado un bug o tienes una propuesta de mejora técnica, abre un [Issue](https://github.com/PablesStayla/PranaKaia-Ecommerce/issues). 
    *   Usa las plantillas proporcionadas.
    *   Incluye logs de error y pasos para reproducir.
3.  **Discusiones**: Para preguntas sobre "cómo hacer X" o debates arquitectónicos, utiliza la pestaña de **Discussions** en GitHub.

## 🚑 Soporte de Producción e Incidentes

Para errores que afectan la operación en vivo (Checkout fallido, caída del Admin, errores de API en producción):

*   **Canal Interno**: Reportar inmediatamente en el canal `#incidents-war-room` de nuestro espacio de comunicación interna.
*   **Email Urgente**: Envía un correo con el prefijo `[P0 - CRITICAL]` a `ops@pranakaia.cl`.

## 🛡 Seguridad y Vulnerabilidades

**No abras un issue público para reportar vulnerabilidades de seguridad.**

Consulta nuestra [Política de Seguridad](./SECURITY.md) para conocer el proceso de reporte responsable o envía un correo directo a `security@pranakaia.cl`.

## 📈 Consultas de Negocio y Operación

Para temas relacionados con el catálogo, dropshipping en Chile o logística que no sean de naturaleza técnica:

*   **Administración**: `admin@pranakaia.cl`
*   **Partners & Dropshipping**: `partners@pranakaia.cl`

---

> **MANTRA DE SOPORTE:** Sé específico, adjunta evidencia y verifica siempre los logs antes de reportar.

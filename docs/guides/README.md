## 💡 Contribution Guidelines

Documentation is a shared responsibility.
- **Atomic PRs**: If you change a process, update the guide in the same PR.
- **Search First**: Before asking in Slack, check the `reference-*` guides.
- **Simplify**: If a guide is too complex, refactor it.

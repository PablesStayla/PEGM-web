# PranaKaia Admin

Backoffice administration panel for PranaKaia E-Commerce.

## Tech Stack

- **Framework**: Next.js 15
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Radix UI (@pranakaia/ui)
- **State Management**: React Query + tRPC
- **Auth**: NextAuth.js (via @pranakaia/next-auth-helpers)

## Getting Started

```bash
pnpm dev
```

Runs on [http://localhost:3001](http://localhost:3001).

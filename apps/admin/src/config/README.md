# Config - Central Configuration

Este directorio contiene la configuracion centralizada de la aplicacion admin.

## Archivos Principales

### resources.config.ts
Registro unico de todos los recursos del admin.

### nav.config.ts
Configuracion de navegacion del sidebar.

### feature-flags.ts
Feature flags para funcionalidades.

## Agregar Nuevo Recurso

1. Anadir a resources.config.ts
2. El sidebar se actualiza automaticamente
3. El RBAC se aplica automaticamente

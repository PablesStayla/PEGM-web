# @pranakaia/ui

**Design System** — Componentes UI Radix con Tailwind CSS para PranaKaia.

## Instalación

```bash
pnpm add @pranakaia/ui
```

## Uso

```typescript
import { Button, Input, Card } from '@pranakaia/ui'
```

## Componentes

- **Button** - Botones primarios, secundarios, outline
- **Input** - Campos de texto con validación
- **Card** - Contenedores modulares
- **Dialog** - Modales y diálogos
- **Toast** - Notificaciones
- **Avatar** - Imágenes de perfil
- **Badge** - Etiquetas de estado
- **Separator** - Separadores visuales

## Exports

| Export | Descripción |
|--------|-------------|
| `@pranakaia/ui` | Barrel export principal |
| `@pranakaia/ui/tailwind.config` | Tailwind configuration |

## Development

```bash
pnpm build
pnpm type-check
pnpm lint
pnpm attw
pnpm publint
```

# @pranakaia/identity

**Identity Bounded Context** — Autenticación, autorización e integración con Better Auth + Supabase.

## Instalación

```bash
pnpm add @pranakaia/identity
```

## Uso

```typescript
import { AuthService, User } from '@pranakaia/identity'
```

## Exports

| Export | Descripción |
|--------|-------------|
| `@pranakaia/identity` | Barrel export principal |
| `@pranakaia/identity/auth` | Authentication module |

## Development

```bash
pnpm build
pnpm type-check
pnpm test
pnpm test:coverage
pnpm lint
pnpm attw
pnpm publint
```

# @pranakaia/pricing

**Pricing Bounded Context** — Cálculo de precios, márgenes, IVA 19% y markup dinámico.

## Instalación

```bash
pnpm add @pranakaia/pricing
```

## Uso

```typescript
import { PricingService, PriceCalculator } from '@pranakaia/pricing'
```

## Exports

| Export | Descripción |

| `@pranakaia/pricing` | Barrel export principal |

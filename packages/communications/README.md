# @pranakaia/communications

**Communications Bounded Context** — Email, SMS y notificaciones vía Resend.

## Instalación

```bash
pnpm add @pranakaia/communications
```

## Uso

```typescript
import { EmailService, SMSNotification } from '@pranakaia/communications'
```
